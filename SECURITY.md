# Security policy

kilngen is pre-alpha; only the latest `main` is supported.

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button (Security tab → Advisories) rather than in a public issue. Include steps to reproduce and the affected version or commit. You should get a response within 7 days.

Areas of particular interest: generated code that mishandles credentials, path traversal in the output writer or workspace path resolution, and the MCP code-execution sandbox (once it exists).
